# Hotel Management System

## 📖 Description
The Hotel Management System is a web-based application developed using Java, JSP, and Oracle Database. It helps manage hotel operations efficiently, including customer bookings, room allocation, employee management, and payment processing.

## 🚀 Features
- Customer registration and booking management
- Room allocation and room type management
- Employee and department management
- Job role management
- Payment processing and invoice generation
- CRUD operations with Oracle database
- User-friendly JSP-based interface

## 🛠 Technologies Used
- Java
- JSP (Java Server Pages)
- Oracle Database
- HTML
- CSS
- JavaScript
- Apache Tomcat

## 📁 Project Structure
Hotel-Management-System/
├── login.jsp
├── booking.jsp
├── customer.jsp
├── employee.jsp
├── payment.jsp
├── room.jsp
├── css/
├── images/
└── database/

## ▶️ How to Run
1. Install JDK and Apache Tomcat
2. Configure Oracle Database
3. Import database tables
4. Deploy the project on Tomcat
5. Open the application in your browser
